# Website review — October 11, 2026

## Scope

Reviewed the 56 public HTML pages, shared scripts, repository maintenance instructions, and state-source coverage. Checked citation presence across the 50 state guides and rechecked selected federal and higher-risk state claims against official sources. This is an editorial and implementation review, not an exhaustive legal opinion or independent verification of the founder's credentials. State coverage is deliberately partial. The 39-state source register still describes that expansion, not every source across the entire site.

## Corrections

- Homepage: replaced unsupported “most often miss” language; clarified that federal protections concern covered businesses; corrected the claim that casket and outer-container prices always require separate lists; changed the itemized statement from a suggestion to a requirement, scoped to in-person arrangements; placed FTC citations beside the six rights cards.
- Nationwide coverage: removed obsolete claims that only NC/SC are researched. Narrowed generic state introductions to selected guidance and contacts rather than implying each page answers all authority, care, and cremation questions.
- Pennsylvania: tied the 24-hour transport threshold to time after death; included metal-lined containers; distinguished the transit permit attached to the case from the burial permit.
- Georgia: corrected the preneed/cemetery oversight referral to the Secretary of State's Securities Division; avoided implying complaint confidentiality means anonymity.
- Connecticut: clarified the prepaid-contract context and agency licensing description.
- Florida: added an actionable official consumer-help link and cleaned malformed statute paths.
- Privacy: described what the site code does, with routine host request processing distinguished from worksheet entries. Removed an absolute promise about future policy-update timing.
- Navigation: interstate parameters no longer assume optional DOM elements exist; both timing sections remain available so linked sections do not disappear.
- Maintenance: retired the obsolete generator, which otherwise would overwrite researched guides with placeholders. Updated README.
- Product: kept all consumer tools free; added a workbook proposal and original starter manuscript. No checkout, paid service, product availability, savings, compliance, or delivery promise added.

## Limits and follow-up

A citation's presence does not establish that every possible legal exception is covered. The guides retain source-review dates, future-effective-law distinctions, and unresolved categories. No claim of comprehensive nationwide compliance is warranted. Revisit New Jersey's upcoming November 1, 2026 change after it becomes effective. Do not turn the existing source register into automated compliance decisions.

The workbook remains a manuscript. Layout, accessible fillable fields, final source review, usability testing, print proof, payment delivery, and actual fulfillment costs are still needed before selling it. Proposed prices are hypotheses, not market validation.

All 56 public HTML pages passed local internal-link, anchor, and duplicate-ID checks. The retired generator exits without changing state pages. A full browser/visual test was attempted but could not run because the Chromium download failed; the DOM harness is not a substitute for visual or full browser testing.
